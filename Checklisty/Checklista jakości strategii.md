# Checklista jakości strategii

*Wypełnij po zakończeniu pracy nad strategią. Jeśli jakiekolwiek pole jest NIE — strategia nie jest gotowa: wróć i popraw.*

## Warunek wejścia (sprawdź NAJPIERW)
- [ ] **Odbyło się discovery** (kwestionariusz/rozmowa z klientem) — strategia NIE jest zbudowana na samych hipotezach.
- [ ] Jeśli działałeś na hipotezach (brak danych) — są one jawnie oznaczone `H1..Hn` i zaplanowana jest walidacja przed wdrożeniem.

## Fundamenty
- [ ] Znamy **segment** docelowy (konkretny, nie „wszyscy").
- [ ] Decyzje oparte na danych (fakty mają źródła), nie na opinii.
- [ ] Wiemy, czego... *nie wiemy* — brakujące dane są oznaczone, nie zignorowane.
- [ ] Klient rozpoznaje się w opisie (persona/job z badań).

## Pozycjonowanie
- [ ] Oświadczenie pozycjonowania jest **jednoznaczne** (segment, kategoria, przewaga, dowód).
- [ ] Przewaga ma konkretny **dowód** (metryka/case).
- [ ] Decyzja o kategorii wynika z perspektywy klienta (nie życzenia firmy).
- [ ] Pozycja jest **defensywna** (trudna do skopiowania, nie „wszyscy tak mówią").
- [ ] Można z niej wyprowadzić komunikację, ofertę, design (spójność).

## Komunikacja
- [ ] Przekaz w **języku klienta** (cytaty), nie marketingowy bełkot.
- [ ] StoryBrand: bohater = klient, my = przewodnik, jasne CTA.
- [ ] Test 5 sekund: odbiorca wie, **dla kogo** i **co robić**.
- [ ] Ton spójny z osobowością marki.

## Oferta
- [ ] Oferta = wartość + zakres + stack + gwarancja + cena + CTA.
- [ ] Wartość postrzegana > cena (klient powie: warto).
- [ ] Gwarancje realne i policzone.

## Tożsamość i design
- [ ] Osobowość/archetyp wynikają ze strategii.
- [ ] Kierunek wizualny jest briefem (uzasadnionym), nie modą.
- [ ] Brand voice da się zastosować (spójnie w materiałach).

## Strona i UX
- [ ] Struktura wg StoryBrand, CTA jednoznaczne.
- [ ] Tarcie zminimalizowane (formularze, cena, gwarancja).
- [ ] Zgodność z 10 [[Frameworki/16 Heurystyki Nielsena|heurystykami NN/g]].

## Walidacja
- [ ] Krytyczne hipotezy przetestowane (realni odbiorcy).
- [ ] Metryki i próg sukcesu zdefiniowane przed wdrożeniem.

## Wniosek
- [ ] Strategia jest **spójna** (każda część wynika z poprzednich).
- [ ] Jest **kompletna** (13 etapów zakończonych artefaktem).
- [ ] Ma **plan wdrożenia** (kto, co, kiedy, jak mierzymy).

---
**Czerwone flagi (od razu popraw):**
- Brak segmentu / pozycjonowanie „dla wszystkich".
- Brak dowodu przewagi.
- Brak danych źródłowych (artefakty „z wyobraźni").
- Brak CTA / brak reakcji użytkownika w testach.
