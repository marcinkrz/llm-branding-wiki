# Oferta

> Wg Alex Hormozi — **oferta = wszystko, co obiecujesz dać** (wartość + stack + gwarancja + cena + CTA). Wypełniaj po komunikacji ([[Playbooki/08 Oferta|playbook]]).

## 1. Rezultat dla klienta
- Jaki konkretny wynik obiecujemy? (z VPC/jobów — nie funkcje)

## 2. Zakres (co klient dokładnie dostaje)
- (konkretnie, granice — bez „elastyczna współpraca")

## 3. Stack wartości (bonusy / dodatki)
- (co jeszcze dokładamy, by podnieść wartość postrzeganą)

## 4. Cena
- **Cena wg wartości:** (oparta o rezultat, nie koszt)
- Warianty (jeśli są): 
  - Podstawowy: ...
  - Plus: ...
  - Premium: ...

## 5. Gwarancja / redukcja ryzyka
- (zwrot, próbka, gwarancja wyniku — tylko jeśli realne!)

## 6. Wezwanie do działania (CTA)
- (jedno, jasne — zgodne ze [[Szablony/StoryBrand|StoryBrand]])

## 7. Spójność z pozycją
- (czy oferta realizuje obietnicę pozycjonowania? jedno zdanie)

## 8. Metryka / test
- Jak zmierzymy, czy oferta działa? (konwersja, WVO — co znaczy sukces)
- Warianty do A/B: ...

---
**Uwaga:** Oferta bez gwarancji i jasnego zakresu = zwykły cennik, nie oferta. Zob. [[Frameworki/13 Marketingu oferty Hormozi|Hormozi]].
