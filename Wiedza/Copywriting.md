# Copywriting

*Nie „pisanie ładnie". Copywriting to komunikacja: framing, oferta, narracja, język klienta. Strategia umiera, jeśli nie zostanie wypowiedziana słowami klienta.*

## Kluczowe zagadnienia

### 1. Język klienta (fundament)
- Strategia zaczyna się od **słów, których używa klient** (z wywiadów, recenzji, supportu).
- Piszesz językiem klienta, nie terminologią firmy.
- Ćwiczenie: zbierz cytaty i buduj przekaz na nich (nie na „marketingu").

### 2. Framing (ramowanie)
- Sposób przedstawienia wpływa na decyzję: „zachowasz 80%" vs „stracisz 20%" ([[Wiedza/Psychologia|psychologia]]).
- Ramuj wg korzyści i tożsamości segmentu, nie wg funkcji.
- Framework do rozumienia: benefit ≠ feature (cecha → korzyść → emocja).

### 3. Narracja (struktura przekazu)
- Klient jest bohaterem, firma przewodnikiem ([[Frameworki/01 StoryBrand|StoryBrand]]).
- Historia: problem → przewodnik → plan → sukces.
- Bez narracji: lista funkcji. Z narracją: jasna rola i CTA.

### 4. Oferta w słowach
- Copywriting łączy się z ofertą ([[Wiedza/Strategia marki|oferta]]): obietnica, dowód, gwarancja, CTA.
- Pisz „co dostaniesz" konkretnie (scope), nie mgliście.
- Gwarancja i ryzyko: komunikuj redukcję ryzyka („bez ryzyka", „30 dni").

### 5. Struktury copy
- **AIDA**: Attention → Interest → Desire → Action.
- **PAS**: Problem → Agitate (pogłębienie bólu) → Solution.
- **FAB**: Features → Advantages → Benefits (cecha → przewaga → korzyść dla klienta).
- **One-liner pozycjonowania**: jedna obietnica w jednym zdaniu.

## Jak to wpływa na decyzje strategiczne
- **Przekaz**: treści muszą przechodzić test „dla kogo i co robić".
- **CTA**: wiedza, gdzie i jak prosić klienta o działanie.
- **SEO/Content**: tematy z pytań klienta, nie z wewnętrznych „fajnych tematów".

- „Marketingowy bełkot" zamiast języka klienta.
- Brak CTA (tekst, który niczego nie prosi).
- Opisywanie funkcji zamiast rezultatu dla klienta.
