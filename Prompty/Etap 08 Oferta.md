# Prompt etapowy: 08 Oferta

*Jeden etap procesu ([[Playbooki/08 Oferta|playbook 08]]) jako osobny prompt — agent prowadzi TYLKO ten etap: wartość, zakres, stack, gwarancja, cena, CTA.*

## Prompt (do skopiowania)

> Działaj jak **strateg marki**. Masz przeprowadzić **tylko etap 08: Oferta** dla: **[BRANŻA / FIRMA]**.
>
> Najpierw przeczytaj `Playbooki/08 Oferta`, `Frameworki/13 Marketingu oferty Hormozi`, `Frameworki/03 Value Proposition Canvas` i `Frameworki/02 Jobs To Be Done`.
>
> Następnie wykonaj po kolei:
> 1. **Wypisz wartość** (z VPC/pozycji) jako rezultat dla klienta.
> 2. Zaprojektuj **zakres** (co dokładnie klient dostaje — granice, nie mglistość).
> 3. Zbuduj **paczkę**: wartość + bonusy + gwarancja + cena + CTA (**Hormozi**).
> 4. Ustaw **ceny** wg postrzeganej wartości (nie kosztów) — 2–3 warianty/poziomy.
> 5. Dodaj **gwarancje/redukcję ryzyka** (zwrot, próbka — tylko realne!).
> 6. Zaproponuj **testy** (A/B ofert, warianty stack/gwarancji) + metrykę (konwersja, WVO).
> 7. Podaj: struktura oferty + warianty + plan testów.
>
> **Zasady:** oferta = wartość + zakres + stack + gwarancja + cena + CTA (nie cennik); obietnice policzone (gwarancje realne); spójne z pozycją.

## Wejście
- Pozycjonowanie (06), komunikacja (07), joby (03), koszty.

## Wynik (artefakt)
- Struktura oferty (wartość + stack + gwarancja + cena + CTA).
- Warianty ofert do testów.
- Plan testów / metryka.

## Weryfikacja
- Klient potrafi powiedzieć, co dokładnie kupuje.
- Wartość postrzegana > cena („warto").
- Gwarancje policzone.
- Oferta spójna z pozycją (nie „rozmienia się na drobne").
