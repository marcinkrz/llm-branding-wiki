# Prompt etapowy: 07 Komunikacja

*Jeden etap procesu ([[Playbooki/07 Komunikacja|playbook 07]]) jako osobny prompt — agent prowadzi TYLKO ten etap: przekaz, StoryBrand, ton, treści.*

## Prompt (do skopiowania)

> Działaj jak **strateg marki**. Masz przeprowadzić **tylko etap 07: Komunikacja** dla: **[BRANŻA / FIRMA]**.
>
> Najpierw przeczytaj `Playbooki/07 Komunikacja`, `Frameworki/01 StoryBrand`, `Frameworki/36 Jezyk klienta VoC`, `Frameworki/14 Inzynieria perswazji Cialdini` i `Frameworki/27 Message House`.
>
> Następnie wykonaj po kolei:
> 1. Zbierz **język klienta** (cytaty z etapu 03) — słowa na problem i rezultat.
> 2. Zbuduj strukturę **StoryBrand**: bohater=klient, problem (zew./wew./filozoficzny), my=przewodnik, plan, CTA (główne+przejściowe), unikanie porażki, sukces.
> 3. Napisz **one-liner** z pozycjonowania (etap 06) — spójny z historią.
> 4. Ustal **ton/głos** ([[Frameworki/12 Osobowosc marki Aaker|osobowość]] / [[Frameworki/17 Archetypy marki|archetyp]]).
> 5. Rozpisz **warianty** dla kanałów (social, e-mail, sales) — jedna historia, różne strefy.
> 6. Podaj: one-liner + struktura strony (sekcje wg StoryBrand) + zasady głosu + warianty.
>
> **Zasady:** tekst o kliencie („Ty"), nie o nas („my"); CTA jednoznaczne; język z badań, nie bełkot; każda sekcja ma zadanie.

## Wejście
- Pozycjonowanie (06), język klienta (03), oferta (jeśli już jest).

## Wynik (artefakt)
- StoryBrand One-Liner + struktura strony (sekcje, CTA).
- Zasady głosu/tonu (co mówimy, czego nie).
- Warianty komunikatów dla kanałów.

## Weryfikacja
- Test 5 sekund: dla kogo i co robić — odpowiedź.
- Dominuje klient („Ty"), nie my.
- Przekaz spójny z pozycją.
- Język klienta (cytaty), nie „marketingowy bełkot".
- Każda sekcja ma zadanie.
