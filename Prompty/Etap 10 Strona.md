# Prompt etapowy: 10 Strona

*Jeden etap procesu ([[Playbooki/10 Strona|playbook 10]]) jako osobny prompt — agent prowadzi TYLKO ten etap: struktura, teksty, UX, CTA, tarcie.*

## Prompt (do skopiowania)

> Działaj jak **strateg marki**. Masz przeprowadzić **tylko etap 10: Strona** dla: **[BRANŻA / FIRMA]**.
>
> Najpierw przeczytaj `Playbooki/10 Strona`, `Frameworki/01 StoryBrand`, `Frameworki/16 Heurystyki Nielsena`, `Frameworki/18 Mapa podrozy klienta` i `Frameworki/37 Tarcie uzytkownika`.
>
> Następnie wykonaj po kolei:
> 1. Ustal **cel strony i metrykę** (lead / sprzedaż / kontakt).
> 2. Zbuduj **strukturę** wg StoryBrand ([[Szablony/Struktura strony|szablon]]): hero(one-liner+CTA) → problem → przewodnik+dowody → plan → korzyści → opinie → oferta+gwarancja → CTA → FAQ+stopka.
> 3. Rozpisz **teksty sekcji** w języku klienta (z etapu 03).
> 4. Zaprojektuj **przepływ UX** wg heurystyk NN/g i podróży klienta.
> 5. **Zminimalizuj tarcie**: krótkie formularze, widoczna cena/gwarancja, jasne CTA (Hormozi/CRO).
> 6. Dodaj **elementy zaufania** (case, loga, gwarancje) — Cialdini.
> 7. Podaj: wireframe (sekcje) + teksty + listę poprawek UX + plan metryk.
>
> **Zasady:** jeden cel = jedna główna akcja; test 5 s (dla kogo, co zrobić); tarcie zminimalizowane; nie kryj oferty.

## Wejście
- Komunikacja/one-liner (07), oferta (08), tożsamość (09), dane o kliencie (03).

## Wynik (artefakt)
- Projekt struktury (wireframe: sekcje, CTA, hierarchia).
- Teksty strony (nagłówki, sekcje, CTA).
- Lista poprawek UX przed wdrożeniem.
- Plan metryk (cel, konwersja, pomiar).

## Weryfikacja
- Test 5 s: dla kogo i co robić.
- CTA jednoznaczne; tarcie zminimalizowane.
- Zgodność z heurystykami NN/g.
- Metryka i pomiar zdefiniowane.
